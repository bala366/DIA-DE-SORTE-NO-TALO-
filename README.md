# Dia de Sorte — Engrossando o Talo V1

Projeto Android para GitHub Actions.

O motor de cálculo foi mantido em Python dentro do APK via Chaquopy, para preservar a mesma mecânica do Pydroid:

- testa perímetros 30 a 180;
- backtest máximo de 500 concursos;
- aprende 1, 2, 3 ou 4 repetidas;
- TOP_UNIVERSO = 21;
- TOP_HEAP = 400;
- quina permitida;
- 6 ou 7 eliminam o candidato;
- ranking final por quadras, ternos, blocos, recentes, quinas, duques, slope, crescimento e score;
- escolhe Mês da Sorte pelo mesmo perímetro.

O APK usa o seletor de arquivos Android para importar o TXT.
